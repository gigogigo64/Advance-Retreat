## 1. 项目定位

本地优先的 Windows 桌面小工具，用于**培养优点、抵制缺点**：

- 优点：「今天我坚持了这个优点了吗？」→ 坚持 = 打卡 ✅
- 缺点：「今天我避开了这个缺点了吗？」→ 避开 = 打卡 🛡️

配合连续天数（streak）、积分、愿望兑换等激励机制，形成正向闭环。

## 3. 功能规格

### 3.1 今日视图（默认主页）
- 日期 + 今日进度环（如 6/8）
- 🟢 优点卡片（点击=今天坚持了）/ 🔴 缺点卡片（点击=今天避开了）
- 打卡反馈：高亮 + 弹性动画 + streak 🔥
- 当日全部完成：🎉 撒花 + 满分积分
- 每条支持 emoji 图标 + 颜色 + 分类标签

### 3.2 清单管理
- 优点/缺点分开管理；名称、emoji、颜色、分类（健康/学习/社交/情绪/自定义）、目标频率（每天/每周N次/仅工作日）、开始日期、备注
- 归档保留历史数据

### 3.3 统计
- 单条：当前连续/最长连续/30天完成率/年度热力图
- 总览：趋势、最佳排行、需警惕排行
- 统计基于真实日期，无补卡

### 3.4 积分与愿望兑换
- 规则：打卡1条+2分；连续7天全勤+10分；满分日+5分（可在设置调整）
- 愿望清单：自定义奖励+所需积分；兑换扣分并留记录

### 3.5 每日一句话回顾
- 今日视图底部轻量输入框，每天一条，当日可编辑

### 3.6 提醒
- 可设提醒时间（默认21:00），到点检查未完成项→系统通知；全完成不打扰；可开关

### 3.7 数据与设置
- SQLite 于 `%APPDATA%/知进退/`；JSON 导出/导入；主题跟随系统+手动切换；强调色可选

## 4. UI / 交互规范
- 侧边栏：**今日 / 统计 / 清单 / 奖励 / 设置**
- shadcn/ui 组件（Dialog、Popover、Toast等），禁止堆叠按钮
- Framer Motion：打卡弹性动效、进度环动画、页面过渡
- 单击卡片=打卡；hover 预览反馈
- 过去日期灰显不可交互
- 视觉：清爽留白、圆角卡片、柔和渐变、活力强调色

## 5. 技术栈
- Tauri 2 + React 18 + Vite + TypeScript
- Tailwind CSS + shadcn/ui + Framer Motion
- SQLite（tauri-plugin-sql）、Recharts + 自绘热力图
- tauri-plugin-notification
