## 一、项目定位

一款**本地优先**的 Windows 桌面小工具，用于**培养优点、抵制缺点**。

核心玩法：用户列出自己的优点与缺点，每天对每一条进行打卡——

- 优点：「今天我坚持了这个优点了吗？」→ 坚持 = 打卡 ✅
- 缺点：「今天我避开了这个缺点了吗？」→ 避开 = 打卡 🛡️

配合连续天数（streak）、积分、愿望兑换等激励机制，形成正向闭环。

## 三、功能规格

### 3.1 今日视图（默认主页）
- 顶部：日期显示 + 今日进度环（如 6/8）
- 两列卡片流：
  - 🟢 优点培养卡片 → 点击 = 「今天坚持了」
  - 🔴 缺点抵制卡片 → 点击 = 「今天避开了」
- 打卡反馈：卡片高亮 + 弹性动画 + streak 🔥 数字变化
- 当日全部完成：🎉 撒花庆祝 + 「今日满分！」+ 满分奖励积分
- 每条记录支持 emoji 图标 + 自定义颜色 + 分类标签

### 3.2 清单管理
- 优点 / 缺点分开管理
- 每条可设置：名称、emoji 图标、颜色、分类（健康/学习/社交/情绪/自定义）、目标频率（每天 / 每周 N 次 / 仅工作日）、开始日期、备注
- 支持归档（保留历史数据，不出现在今日视图中）

### 3.3 统计
- 单条记录：当前连续 🔥 / 最长连续 / 30 天完成率 / GitHub 式年度热力图
- 总览：整体趋势、最佳习惯排行、「需要警惕」排行（近期失败最多）
- 补卡禁止：统计基于真实日期记录

### 3.4 积分与愿望兑换
- 积分规则（v1 初始值，可在设置中调整）：
  - 每日打卡 1 条：+2 分
  - 连续 7 天全部完成：额外 +10 分
  - 当日全部完成（满分日）：+5 分
- 愿望清单：自定义奖励 + 所需积分（如「看一场电影 = 50 分」）
- 兑换：扣减积分，保留兑换历史记录

### 3.5 每日一句话回顾
- 今日视图底部：一个轻量输入框「今天，一句话总结」
- 每天最多一条，可编辑当日内容；历史回顾可在日历/统计中查看

### 3.6 提醒
- 用户可设定提醒时间（默认 21:00）
- 到点检查：若今日仍有未打卡项 → 系统通知（Tauri notification）提醒打卡
- 当日全部完成则不打扰
- 设置中可开关

### 3.7 数据与设置
- SQLite 单文件本地存储（数据目录：`%APPDATA%/知进退/`）
- 一键导出 / 导入 JSON 备份
- 深色 / 浅色主题（跟随系统 + 手动切换）、强调色可选

## 四、UI / 交互规范

- 侧边栏导航：**今日 / 统计 / 清单 / 奖励 / 设置**
- 使用 shadcn/ui 成熟交互组件（Dialog、Popover、Command、Toast 等），禁止简单堆叠按钮
- Framer Motion 动效：打卡弹性反馈、进度环动画、页面过渡
- 打卡是**单击卡片**完成的核心动作，hover 有预览反馈
- 过去日期在日历视图中灰显不可交互（补卡禁止的可视化表达）
- 视觉基调：清爽留白、圆角卡片、柔和渐变点缀、活力强调色

5. 每日一句话可写可查
6. 定时提醒生效
