# 知进退 · Advance & Retreat

> 培养优点，抵制缺点 —— 本地优先的每日打卡激励工具

## 🚀 直接运行

双击根目录下的 **`知进退.exe`** 即可使用（免安装、绿色版，数据存在本机）。

需要安装到系统（开始菜单快捷方式）则运行 **`知进退-安装包.exe`**。

## ✨ 功能

- **今日打卡**：优点「今天坚持了吗」/ 缺点「今天避开了吗」，单击卡片即可打卡
- **禁止补卡**：只有当天能打卡，过去就过去了
- **缺点 Boss 化**：每个缺点是带血条的 Boss，每天成功避开削弱 3 HP；击败后由 AI（GLM 工具调用）自动转化为对应好习惯并归档，可一键撤销
- **可自定义**：每条优缺点的血量上限、每次扣血、完成加分均可单独设置；清单支持拖拽或 ▲▼ 调序
- **连续天数**：🔥 当前连续 / 最长连续 / 30天完成率 / 年度热力图
- **每日一句话回顾**：记录当天心情或总结
- **积分激励**：打卡得分，连续 7 天全勤和每日满分有额外奖励
- **愿望兑换**：用积分兑换自己的奖励，形成正向闭环
- **定时提醒**：到点若还有未打卡项会弹系统通知
- **本地存储**：SQLite 单文件（`%APPDATA%/com.gigogigo64.advance-retreat/`），可导出/导入 JSON 备份

## 📁 目录结构

```
优缺点培养/
├── 知进退.exe              ← 双击运行（绿色版）
├── 知进退-安装包.exe        ← 系统安装包
├── scripts/               ← 构建部署脚本
├── docs/规范.md            ← 项目规范（需求定稿+约定）
├── dev/                   ← 开发计划与日志（临时文档）
└── advance-retreat/       ← Tauri 项目源码
```

## 🔧 开发

```bash
cd advance-retreat
npm install
npm run tauri dev          # 开发模式
```

重新构建并自动部署到根目录：

```bash
cd advance-retreat
npm run deploy           # = node ../scripts/build-and-deploy.mjs
```
